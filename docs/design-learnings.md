# 获奖网页设计 · 学习笔记

> 用途：为「希望工作室 / 归档处」网站的后续改版提供设计依据。
> 素材来源：Awwwards / Webby 等获奖网站评审标准与名站分析、
> Linear 与 Framer 两套设计系统的逆向拆解、本站的可量化设计审计。

---

## 一、奖项到底在评什么

不同奖项的评审维度大同小异，核心是这几件事：

| 奖项 | 主要评审维度 |
|---|---|
| **Awwwards** | Design（美学与版式）、Usability（易用性）、Creativity（原创性）、Content（内容质量）四维综合 |
| **FWA** | 更偏技术/前沿：新技术应用、实验性交互、WebGL/3D、动效质感 |
| **CSS Design Awards** | 视觉设计、用户体验、动效、代码质量、可访问性 |
| **Webby** | 内容、结构/导航、视觉、功能、用户体验，另设无障碍专项 |

**核心洞察**：获奖 ≠ 好看。评审把 **Creativity 与 Content** 抬得很高——真正获奖的站往往是因为「用一种别人没做过的形式讲了一个扎实的内容」，而不是因为堆特效。Awwwards 官方博客多次强调「形式要服务于内容」。

## 二、两套名站设计系统的逆向拆解

我从两套备受推崇的「工程感极强」的网站设计系统里抽出了可直接对照的 token。

### Linear（软件产品官网，近黑 + 单一强调色）

- **颜色**：画布近纯黑 `#010102`，卡片炭灰 `#0f1011`（逐级抬升 surface-1..4），发丝级描边 `#23252a`；文字用多层灰阶 `#f7f8f8 / #d0d6e0 / #8a8f98 / #62666d`。**唯一**的彩色是薰衣草蓝 `#5e6ad2`——只出现在品牌标、焦点环和少数 CTA 上，**绝不装饰性滥用**。
- **排版**：显示级字号 80/56/40/28px，字重 600，`letterSpacing` **负向**收紧（-3.0 / -1.8 / -1.0 / -0.6px）；正文 16px、行高 1.5。标题负字距 + 正文宽松行高 = 典型的「工程文档感」。
- **节奏**：用产品 UI 截图（装在深色面板里）撑起页面节奏，而不是靠氛围色。

### Framer（建站工具官网，纯黑 + 激进大字）

- **颜色**：纯黑 `#090909`，表面 `#141414/#1c1c1c`，发丝 `#262626`；单一蓝 `#0099ff` 只留给链接和选区。**大色块的渐变氛围面板**（品红/紫/橙）作为「活的展示块」打破节奏。
- **排版**：显示级字号 110/85/62px，**lineHeight 压到 0.85–1.0**，`letterSpacing` -5.5 ~ -3.1px——「贴得够紧，看起来像海报」。CTA 一律是白胶囊/黑字。
- **关键手法**：把「留白」压到近零（line-height < 1）制造冲击，再用大字号 + 负字距做出高级感。

### 从中提炼的可操作规则

1. **强调色要克制**：一个站点只能有**一个**主强调色，用于「品牌 / 焦点 / 关键 CTA」，其余全用中性灰阶分层。滥用强调色是「业余感」的头号来源。
2. **发丝描边**：卡片之间用 1px 低对比描边（hairline）分层，比大投影更高级、更可控。
3. **文字靠多层灰阶**分层（ink / muted / subtle / tertiary），而不是靠不同颜色。
4. **标题负字距 + 正文行高 1.5–1.7**，显示级可以 line-height < 1。
5. **字号刻度要收敛**：一套 6–10 档的 type scale（如 12/14/16/18/22/28/40/56），不要满页面散落几十个不连续的字号。

## 三、本站的设计审计（可量化结果）

用 `scripts/audit-design.mjs` 对线上页面实测，结论如下：

**对比度（WCAG AA 需 ≥ 4.5:1）**
- 首页：正文段落最低 **4.19:1**（一个 9.6px 元素）、小字/标签 **3.68:1**（12px）→ **不达标**，需修。
- /posts、/archive：全达标 ✓；阅读器：正文 8.36:1、链接 5.01:1 ✓。

**触控目标**：全部页面 0 个低于 24px（AA 达标），但低于 44px（AAA 目标）的每页有 11–16 个（导航小字、工具栏图标按钮等）。

**字号分布**：首页出现约 **12 个不同字号**（9.6/10/12/12.8/13.6/14/15.2/16/19.2/25.6/36.8/38.4px）——**刻度碎片化**，与名站「收敛的 type scale」相悖。根因是 20px 根字号下混用了各种 em/rem 倍率。

**减弱动效（prefers-reduced-motion）**：修复前 `portal-gallery`、`news` 组件的悬停过渡用了 `transition: all .3s ease !important`，会**击穿**全局 reduced-motion 覆盖——已修（改为 `@media (no-preference)` 包裹），修复后 reduce 模式下仍在动的元素从 12 个降到 0。

## 四、对本站的落地方案（按优先级）

| 优先级 | 改进 | 依据 |
|---|---|---|
| 高 | 收敛字号刻度：把分散的 12+ 个字号整理成一套 type scale，正文统一 16px、行高 1.6–1.7 | 三.4 / 三.5 |
| 高 | 修首页小字对比度（12px 3.68:1 → 提到 ≥4.5:1，或加大字号到 14px 再调灰） | 三.1 |
| 中 | 强调色收敛：目前政务蓝+青色+紫+红多处使用，收敛为「一个主色 + 灰阶分层」 | 二.1 |
| 中 | 触控目标提到 44px（导航项、工具栏图标按钮加 padding） | 三.2 / WCAG 2.5.5 |
| 低 | 卡片投影改发丝描边或保留但降强度 | 二.2 |
| 低 | 大标题用负字距（中文可微负，英文明显） | 二.5 |

> 注：政务/机构类网站不宜照搬 Framer 的激进大字（line-height 0.85）——可读性与庄重感优先，但「收敛 type scale、克制强调色、文字灰阶分层、发丝描边」这套**工程感**完全适用。

## 五、反向提醒（获奖 ≠ 好用）

- 很多获奖站为「Wow 效果」牺牲**性能**（大 WebGL、高清视频、滚动绑定）和**无障碍**（无键盘可达、低对比、动效无 reduced-motion 处理）。Awwwards 官方与业界对此有持续批评。
- 本站的定位是**公共服务 + 电子资料归档**，优先级应是：**内容可读 > 可达性合规 > 克制的美学**。上面四的方案都是「低风险提质感」，没有牺牲可读性。
