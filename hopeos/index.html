HopeOS.

从 UEFI 开始，自己写一个操作系统。

从内核线程、抢占式调度、虚拟文件系统，到 ring 3 用户态与 POSIX 系统调用，再到自研平铺窗口管理器、StarDustUI 原生桌面与 GNU 工具链—— 每一层都从零实现。目标不是做一个玩具，而是弄清楚一台计算机到底是怎么跑起来的。

自研 WM、原生 shell 与 GNU 工具链

2026.11 · QEMU 实拍

这一轮把桌面与用户态继续往上推：内核里长出了自研平铺窗口管理器， StarDustUI 写出了两套原生桌面 shell，GNU coreutils 也被完整接进 /bin/gnu——底下补的是 statx、*at、#! 脚本解释这些通用内核能力。

01

自研平铺窗口管理器

内核态 WM：TILE / GRID / MONOCLE 三种布局、6px gap、4 个工作区、Alt 快捷键，ring-3 窗口也可opt-in 参与平铺。

02

Two shells, one framework

StarDust Desktop 与 HopeOS 95 都是 StarDustUI 写的原生桌面：星空壁纸 / dock，以及 Win9x 风格的 iframe 式窗口。

03

GNU 工具链落地

GNU coreutils 9.5 以单二进制 + 105 个 applet 装进 /bin/gnu；为它补上 statx、faccessat、*at 与 #! 脚本支持。

04

X11 + IceWM 稳定运行

从零实现的 X 协议子集配上上游 IceWM：窗口收养、标题栏、任务栏与开始菜单，XTerm 等客户端常驻。

13 个子系统
01内核

内存管理

隐式空闲链表堆分配器（mm.c），分页与 COW 页表；用户态进程独立地址空间。

02内核

中断 / 定时器

自接管 GDT/TSS、256 项 IDT、APIC/IOAPIC、PIT 100 Hz、ExitBootServices。

03内核

抢占式调度器

内核线程、100 Hz 时间片、栈金丝雀；调度器主路径回收已退出线程。

04内核

VFS + ramfs + FAT32

ramfs 承载整个 /bin；只读 FAT32 解析让 ESP 上的文件在启动时被装进 ramfs。

05内核

VFS 符号链接

ramfs symlink 节点：symlinkat / readlink / lstat / statx 的 NOFOLLOW，路径解析跟随链接并检测环路（ELOOP）。

06内核

lwIP 网络栈

IPv4 / ARP / ICMP / UDP / TCP / DHCP / DNS，用户态 socket 与 pipes 已接通。

07图形

内核 GUI 桌面

离屏双缓冲 + 脏矩形合成，原生窗口、任务栏与桌面组件（计算器、时钟、画图…）。

08图形

PS/2 键鼠输入

键盘、鼠标输入解码，并把事件路由到活动窗口；支持 Alt+Tab 与窗口拖动。

09图形

X11 服务器 + IceWM

X 协议子集、窗口与事件、帧缓冲呈现；IceWM 负责窗口管理与任务栏。

10图形

自研平铺 WM

TILE / GRID / MONOCLE 三布局、gap、4 工作区、Alt 拖动浮动窗口、ring-3 客户端接入。

11用户态

ring 3 + POSIX syscall

分页、DPL3 描述符、SYSCALL 门；每进程 fd/cwd、fork/execve、重定向与管道。

12用户态

StarDustUI 原生 shell

StarDust Desktop（星空壁纸 + dock）与 HopeOS 95（Win9x 风格）都跑在 StarDustUI 上。

13用户态

GNU coreutils + BusyBox

coreutils 9.5 单二进制 105 applet；BusyBox 1.36.1 作为 /bin 基础工具集与脚本解释器。

接下来做什么

持续更新
  1. 计划中

    GUI 临界区 SMP 安全

    窗口系统与合成器目前靠关中断保护；换成细粒度 spinlock，多核下也能稳定刷新。

  2. 计划中

    可写、持久化文件系统

    把 ramfs 内容持久化到磁盘镜像（AHCI/NVMe），重启后仍然存在。

  3. 计划中

    用户态 libc 完善

    补齐信号、stdio 缓冲与线程，承载更多第三方程序。

  4. 计划中

    设备驱动

    NVMe / USB / GPU：先把存储与输入设备补齐，再谈硬件加速图形。

  5. 极远

    承载 JVM → 跑 Minecraft

    需要足够 POSIX + GPU 图形，属于极远远期终态，学习旅程本身才是重点。
