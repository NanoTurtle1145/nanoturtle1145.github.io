HopeOS.

从 UEFI 开始，自己写一个操作系统。

从内核线程、抢占式调度、虚拟文件系统，到 ring 3 用户态与 POSIX 系统调用，再到今天跑起来的 X11 + IceWM 桌面——每一层都从零实现。 目标不是做一个玩具，而是弄清楚一台计算机到底是怎么跑起来的。

9 个子系统
01内核

内存管理

隐式空闲链表堆分配器（mm.c），8 MiB 堆；分页与 COW 页表已经就位。

02内核

中断 / 定时器

自接管 GDT/TSS、256 项 IDT、8259 重映射、PIT 100 Hz、ExitBootServices。

03内核

抢占式调度器

内核线程、100 Hz 时间片、栈金丝雀；调度器主路径回收已退出线程。

04内核

VFS + ramfs

文件系统接入内核，支持目录与文件读写，用户态可以正常访问。

05图形

GUI 桌面

离屏双缓冲 + 脏矩形合成，原生窗口、任务栏与桌面组件。

06图形

PS/2 键鼠输入

键盘、鼠标输入解码，并把事件路由到活动窗口。

07图形

X11 服务器 + IceWM

X 协议子集、窗口与事件、帧缓冲呈现；IceWM 负责窗口管理与任务栏。

08用户态

ring 3 + 系统调用

分页基础设施、DPL3 描述符、0x80 syscall 门，用户程序在 ring 3 运行。

09用户态

POSIX 内核

每进程 fd/cwd、fork/execve/重定向、用户态 shell、最小 libc。

持续更新
  1. 进行中

    IceWM 桌面收尾

    补齐 XPM 图标、桌面壁纸、任务栏时钟刷新与窗口拖拽细节。

  2. 进行中

    按需缺页（demand paging）

    在已有 COW + 可返回 #PF 的基础上，补齐真正的按需分页。

  3. 计划中

    可写、持久化文件系统

    把 ramfs 内容持久化到磁盘镜像，重启后仍然存在。

  4. 计划中

    用户态 libc 完善 + 工具链

    补齐 malloc / 信号 / stdio 缓冲，可承载更多第三方程序。

  5. 计划中

    设备驱动

    先网络，再 GPU / 存储（AHCI、NVMe、USB）。

  6. 远期

    兼容 BusyBox

    PIE 加载 + auxv + arch_prctl + mmap/brk + 信号，分 A~E 阶段推进。

  7. 极远

    承载 JVM → 跑 Minecraft

    需要足够 POSIX + GPU 图形，属于极远远期终态，学习旅程本身才是重点。
